## The closed-loop quality architecture (the heart of the system)

Master spec: `docs/superpowers/specs/2026-06-03-self-correcting-quality-architecture-design.md`. Built + proven in `research/quality_loop/`:

- **Perception (`perception.py`)** — deterministic facts read off a rendered page PNG/PDF: `empty_gap` (the unified emptiness metric — see below), `display_font_embedded`, `min_text_contrast`, `required_slots_missing`, `non_numeral_stat_values`, `placeholder_text_present`, `header_furniture_present`, `qr_gating_violation`.
- **Rubric (`rubric.py`)** — the two tables from DNA §C (positive) / §E (negative) as versioned config; each row DET or VIS, weight or HARD-FAIL, knob_class (renderer/preprocessor/asset_gen). Key rows: N01 missing photo (hard-fail→asset_gen), N03 font fallback, N08 dead/hollow space (→renderer), N15 prose-as-stat (→preprocessor), P01/P05/P07/P11/P16 founder/photo/social-proof/charts/mockups (VIS).
- **Analysis (`analysis.py`)** — `score(facts, refs, rubric, vis_results=None) -> PageScore` (reward 0–1M, hard-fail dominance, anti-reward-hacking caps, DET-gates-VIS so no positive is awarded on the VIS half alone). `vis_results=None` = DET-only (VIS rows skipped, never silently passed).
- **VIS comparison (`vis_client.py` + `vis_prompt.py`)** — real OpenRouter (sync httpx, temp 0, on-disk cache, fence-tolerant JSON parse) + `FakeVisionClient`. Brand-agnostic prompt judges composition vs the matched reference pages.
- **Reference library (`references/`)** — all 6 Richard decks rasterized (84 pages), tagged with per-deck axes (DNA §B) + st_type via **deterministic FALLSTUDIE text-layer detection** (`classify.py`). `retrieve_references(st_type, axes, k)` anchors VIS against multi-deck same-type pages.
- **Conductor (`conductor.py`)** — turns the top defect into a Fix and routes it: renderer-class → apply a knob + re-render (knobs: `density` ladder, `case_study_layout` fill for `FILL_CAPABLE_ST_TYPES={ST-07A,ST-22,ST-FAZIT}`); asset_gen/preprocessor → FLAG (no fabrication).
- **Brain (`brain.py`)** — `converge_page` (per-page loop + 3 guards: iteration cap, monotone-best, oscillation → clear or ship-best+flags) and `converge_deck` (whole-deck, aggregates flags by owner).

**The unified emptiness metric (`empty_gap`) — the anti-gaming core.** N08 fires when the largest contiguous run of uniform near-white OR uniform near-dark rows (over the central content column, margins cropped) > 0.13. This catches BOTH white gaps AND hollow dark/colored panels. Calibrated on real pages: hollow ST-07B dark void 0.293 FIRES; genuinely packed case-study stat panel 0.067 CLEARS; Richard's packed dark panels 0.018–0.051 clear. This replaced a white-only metric that was gameable by painting emptiness dark.

## Hard-won lessons (DO NOT relearn)

- **Brand-agnostic pollution = the cardinal sin** (see rule above). Guards are the structural lock.
- **Metric-gaming / Goodhart (the audit lesson):** I optimized a cheap proxy (whitespace) and even gamed it (a dark void "passed" the white-only metric). "Dead-space cleared" ≠ "good design." The unified emptiness metric + VIS richness rows are the gaming-proof fix. **Verify the actual pixels/images, never trust a "filled"/"passed" count** — that's how both the dark-void and the busy-thumbnail bugs were caught.
- **Font-loading (WeasyPrint 68.1 + homebrew fontconfig 2.18):** a bundled `@font-face` font loads ONLY if its cmap has a **format-12** subtable. Only the **Adobe Source family** (Source Serif 4 / Source Sans 3) loads here; Montserrat/Playfair/Fraunces/EB-Garamond etc. (format-4-only) silently fall back to system PT-Serif/Hiragino. Always (a) pass `FontConfiguration()` to write_pdf/render, (b) verify embedding with `pdffonts`/PyMuPDF NOT a visual diff (0% diff can mean "fallback both times"), (c) render one-doc-per-process in tests (fontconfig leaks state across renders). ⚠️ Production risk: an arbitrary client brand font may not load locally — resolve via OS/Docker font-install path on Railway/Linux (UNVERIFIED). APEX's real "Gestura Headline" is commercial (Sociotype).
- **Subagents mis-report (esp. page counts + "all green"):** verify independently (fitz page count, re-run the suite from the correct dir, view the actual image). A parallel-render race once caused a transient test failure that vanished on a clean serial run.
- **Instagram anti-bot (2026):** public scraping needs residential/mobile proxies (datacenter IPs rejected), curl_cffi TLS impersonation, sticky sessions; GraphQL ids rotate ~2–4 weeks. Free instaloader works low-volume but blocks (403) easily → best-effort with graceful failure.
- **Face-upscaling caveat:** heavily upscaling a real founder's face (CodeFormer/GFPGAN) looks "waxy"/fake. Prefer the high-res source, upscale conservatively, VIS-gate against "looks generated."
- **WeasyPrint quirks:** backgrounds paint on the block (not abspos inset:0); an empty flex/min-height box won't paint; a full-height absolutely-positioned panel needs a DEFINITE container height (`.cs-fill-root{height:261mm}`, the A4 content box). Python 3.11: no backslash inside f-string `{…}`.
