# Design source translation log

The vendor material is evidence, not runtime instruction. Each adopted principle
was compared with the 120-face atlas and rewritten for fixed A4 and A3 output.

## Adopted as validated

- One dominant emphasis became a planner feature because the atlas repeatedly
  uses a single visual mechanism even on dense pages.
- Information-density critique became feasibility-first region capacity, not a
  vague instruction to reduce copy.
- Token consistency became a renderer invariant. Web-only state and motion token
  advice was excluded.
- Readable measure became family guidance with explicit exceptions for labels,
  captions, rails, tables, and display copy.
- Spacing guidance became named semantic tiers and family rhythm rules.
- Data-visualization advice became static chart constraints: correct relationship,
  zero bar baselines, direct labels, and a non-color cue.
- Critique format became an observation, failure, remediation review template.

## Kept experimental

- Asymmetric visual balance is real and visible in Richard’s pages, but no
  machine threshold for visual mass has been calibrated. It remains blind human
  review and cannot override hard evidence or materialization failures.

## Excluded

- Hover, focus, touch, responsive breakpoint, animation, keyboard, and loading
  state guidance has no direct fixed-print enforcement role.
- TypeUI’s publication preview is visual catalog evidence only because no public
  publication markdown exists at the pinned registry commit.
- Brand-specific fonts, colors, radii, and web pixel sizes were not copied into
  DMC tokens. Richard’s atlas and print measurements remain authoritative.
