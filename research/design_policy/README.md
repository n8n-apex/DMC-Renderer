# Design-policy evidence

This directory snapshots selected public MIT material at exact commits, then
translates it into print-specific DMC policies. Runtime code never fetches or
injects upstream skill text. `sync_sources.py --verify` hashes local snapshots
only.

TypeUI’s public repository includes universal fundamentals, editorial and
publication catalog previews, and a public-registry link. Its pinned public
registry currently provides editorial markdown but no publication markdown.
The publication preview is retained as visual evidence only. No paid or premium
TypeUI material is copied or treated as policy.

Designer Skills selections are limited to composition, information density,
typography, hierarchy, color, tokens, data visualization, governance, review,
QA, and handoff. Interactive-only guidance is excluded from the print policy.
